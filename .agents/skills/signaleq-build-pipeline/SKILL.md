# Build pipeline discipline

flagships.html and index_budget_phones.html each contain a
`const PHONES = [...]` block that is GENERATED by build.py, not
hand-edited. Editing a CSV without rerunning the build leaves the live
site silently stale.

Procedure:
1. After any edit to phones_flagship.csv or phones_budget.csv, run:
   `python build.py` (or `python build.py flagship` / `budget` for one tier)
2. Confirm the script printed a success line for the tier(s) touched, not
   a "Could not find 'const PHONES = [...]'" warning.
3. Confirm the corresponding rankings_<tier>.json file's contents changed
   in a way consistent with the CSV edit.
4. Do not mark a CSV-touching task done until steps 1-3 pass. Commit the
   CSV and the regenerated HTML/JSON together.
